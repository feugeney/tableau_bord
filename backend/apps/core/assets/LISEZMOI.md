# Armoiries utilisées dans les PDF

`armoiries.png` est une conversion raster fidèle de `frontend/src/assets/armoiries.svg`.
Source : Wikimedia Commons, « Coat of arms of Guinea.svg », Turn685 d'après Ttzavaras,
licence CC BY-SA 3.0 : https://creativecommons.org/licenses/by-sa/3.0/.
La mention d'attribution figure dans chaque PDF. Remplacer cette image et adapter
la mention dans `export_pdf.py` lorsque le ministère fournit les armoiries officielles.
